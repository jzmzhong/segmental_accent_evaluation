# Segmental Accent Evaluation

This repository contains tools used in the paper [Beyond Utterance-Level Speaker Similarity: Perception-Aligned Segmental Evaluation of Accent in Speech Generation](https://arxiv.org/abs/2610.37912). The [recording_evaluation_interface](./recording_evaluation_interface/) directory contains templates and code for building speech recording and evaluation interfaces. Code for analyzing subjective annotations alongside objective metrics will be added to [subjective_objective_correlation](./subjective_objective_correlation/).

The recordings, generated speech, ratings, and segmental annotations are available on [Hugging Face](https://huggingface.co/datasets/jzmzhong/segmental_accent_annotation). Explore visualizations of the ratings, annotations, and their relationships with objective metrics in the [interactive results viewer](https://jzmzhong.github.io/Segmental-Accent-Evaluation/results.html).
